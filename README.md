# Spruce

A DNS server written in **C++**, built to understand the DNS protocol, UDP networking, packet serialization, and name resolution by implementing them from scratch.

## Features

### Core Server
- [ ] Setup UDP server
- [ ] Receive DNS queries
- [ ] Send DNS responses

### Packet Construction
- [ ] Write DNS header
- [ ] Write question section
- [ ] Write answer section

### Packet Parsing
- [ ] Parse DNS header
- [ ] Parse question section
- [ ] Parse compressed domain names

### Resolution
- [ ] Forward queries to an upstream DNS server
